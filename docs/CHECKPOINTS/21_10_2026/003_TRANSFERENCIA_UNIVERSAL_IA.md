# 3. PRINCIPIOS NO NEGOCIABLES

- THINK != VERIFY != AUTHORIZE != EXECUTE
- CONTEXT != AUTHORITY
- MEMORY != TRUTH
- RAG != VERIFICATION
- EVIDENCE != AUTHORIZATION
- MODEL OUTPUT != EXECUTION PERMISSION

Distinguir siempre:
- Documentado: aparece en documentación.
- Observado: se comprobó en un archivo, comando o salida.
- Implementado: existe código correspondiente.
- Validado: hay una prueba o evidencia suficiente de su comportamiento.
- Pendiente: falta comprobarlo o terminarlo.

La existencia de código no demuestra que funcione.
La existencia de un checkpoint no demuestra que el sistema esté operativo.
No inventar estado, resultados, pruebas, módulos o capacidades.
